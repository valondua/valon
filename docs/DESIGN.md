# Editorial design and photography

The owner's requested reference is [Tim Ferriss's website](https://tim.blog/): a prominent personal introduction, newsletter-led entry, selected starting points and visual interviews. This theme uses Valon's own photography, editorial voice and existing media coverage. It does not reuse Tim's photos, endorsements, copy or subscriber claims.

Only selected supplied photos are used. Captions do not assign dates to the photos or identify other people. They are presentation assets, not evidence that a pictured moment illustrates a historical article event. Decorative article thumbnails have empty alt text; page portraits and photo-journal images have English/Albanian descriptions.

Default page-introduction photos live in `template-parts/page-intro.php`. A featured image selected in Gutenberg overrides the route's default. The homepage retains the existing `valon_portrait` theme setting override. CSS controls visual crops without changing the original photos.

## Review boundary

Core page copy, captions and the newsletter offer are visible in the local review preview. Launch still requires the owner's content review and the connection/deployment steps in `DEPLOYMENT.md`. Social and newsletter connections are not represented as complete.
