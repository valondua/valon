# Sami Frashëri downloads

Scoped landing page and eight public-distribution PDFs. Manifest preserves original SHA-256 hashes, page counts and language labels. The PDF binaries are GitHub release assets (`sami-frasheri-public-2026`) and served from WordPress uploads `/sami-frasheri-2026/`; they are deliberately outside the theme archive. Never substitute the private illustrated versions.

Deploy only `page-sami-frasheri.php` and `assets/sami-frasheri/` to the active theme through the existing Railway route. Download the eight release PDFs to the named uploads directory and verify all hashes. Run `publish.php` with its adjacent manifest once. It refuses a slug collision and validates every PDF before publishing a new Albanian page. It does not edit existing articles or SEO settings. Yoast supplies canonical/share metadata. Preserve these files in future theme deployments.

Online source: ALBANIANA digital edition 2015, 112 pages, external link only; not an 1899 facsimile. Reading text: Fletoret transcription, credited on the page and in the PDFs. Public portrait credits are in assets/sami-frasheri/CREDITS.md.
